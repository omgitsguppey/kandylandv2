# Preflight Checklist

**MANDATORY:** Answer these questions before touching any code.

1. [ ] **What task type is this?** (See `03-TASK-ROUTING.yaml`)
2. [ ] **Who owns it?** (Are you the assigned agent? See `02-AGENT-ROLES.yaml`)
3. [ ] **Which doctrine files apply?** (See `08-DOCTRINE-INDEX.md`)
4. [ ] **What source-of-truth path is involved?** (See `06-SOURCE-OF-TRUTH-MAP.yaml`)
5. [ ] **What shared components are involved?** (See `07-SHARED-COMPONENT-OWNERSHIP.yaml`)
6. [ ] **What telemetry/admin truth paths are involved?**
7. [ ] **What adjacent logic could break?**
8. [ ] **Is this within your allowed boundary?** (See `05-CAPABILITIES-AND-CONSTRAINTS.yaml`)
9. [ ] **What should NOT be touched?** (e.g., economy ledger, payments)

If you cannot answer all of these, do not proceed. Request clarification or hand off the task.
