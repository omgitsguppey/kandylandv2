# Postflight Checklist

**MANDATORY:** Answer these questions before claiming a task is done.

1. [ ] **Was the intended owner respected?** (Did you stay in your lane?)
2. [ ] **Were doctrine files actually consulted?** (Does the copy and UI match the premium candy-coded aesthetic?)
3. [ ] **Were adjacent logic and truth paths checked?**
4. [ ] **Are there stale/fallback/partial states introduced?** (If so, are they explicitly labeled?)
5. [ ] **Was telemetry/admin truth impacted?** (Did you update the required hooks/events?)
6. [ ] **Are files still appropriately sized?** (No massive monoliths?)
7. [ ] **Is a handoff required?** (See `09-HANDOFFS.md`)
8. [ ] **What remains unverified?** (Be honest about what you could not test.)
9. [ ] **What proof exists?** (e.g., Typescript compiler passes, ESLint passes.)
