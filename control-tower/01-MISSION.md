# Mission & Product Phase

## Current Product Phase
KandyDrops is currently in the **Hardening, Truth, Stability, and Refinement** phase.

## Current Priorities
All engineering and agentic efforts must serve these goals:
* **Source of Truth:** Ensuring the UI strictly reflects canonical data, not fabricated state.
* **Realtime Correctness:** Using live telemetry and accurate hooks.
* **UI Stability:** Enforcing design doctrine and layout integrity.
* **Admin Truth:** Ensuring diagnostic surfaces ingest real, accurate data.
* **Telemetry Integrity:** Properly reporting user and conversion actions.
* **Accessibility & SEO Visibility:** Upholding semantic, indexable, accessible web standards.
* **Maintainability:** Utilizing shared components and explicitly designated owners.

## Non-Priorities
Do NOT spend time or token budgets on:
* **Unnecessary New Feature Sprawl:** Do not build entirely new systems outside the current mandate.
* **Fake Realtime:** Do not build UIs that pretend to be realtime via client-side polling hacks if a proper stream is required.
* **Cosmetic Overengineering:** Do not rebuild perfectly fine shared components.
* **Payment/Economy Experimentation:** The GumDrops economy and PayPal infrastructure are strictly off-limits unless explicitly authorized by core leadership.
