# Quick Routing Cheat Sheet

**Who should do this task?**

*   **Is it Architecture, Firebase, Shared Components, or Environment?** -> `antigravity`
*   **Is it an isolated UI fix, CSS tweak, or bounded bug fix?** -> `jules`
*   **Is it a verification pass, audit, or copy review?** -> `codex_or_gpt`

**What if it's mixed?**
Do not attempt mixed tasks in one prompt. Split the task before coding. Let `antigravity` build the architecture, then let `jules` implement the UI against it.
