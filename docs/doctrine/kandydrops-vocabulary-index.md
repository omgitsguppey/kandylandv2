# KandyDrops Vocabulary Index

This index defines the strictly approved vocabulary for KandyDrops, categorized by intention. It also explicitly lists forbidden substitutes. This index is intended for both human developers and agentic tools to enforce brand consistency.

## 1. The Economy (Access & Value)
| Approved | Forbidden Substitutes | Context |
| :--- | :--- | :--- |
| **GumDrops** | Tokens, Credits, Points, Coins | The primary internal currency. |
| **Unlock** | Buy, Purchase, Pay | Used when a user spends GumDrops to access content. |
| **Refill** | Buy More, Add Funds | Used when a user is acquiring more GumDrops via fiat. |

## 2. Content & Experiences
| Approved | Forbidden Substitutes | Context |
| :--- | :--- | :--- |
| **Drop** | Post, Video, Item | A specific piece of premium content. |
| **Experience** | Tier, Package, Bundle | A collection of Drops or deeper access to a creator. |
| **Creator** | Influencer, User, Seller | The entity providing the Drop/Experience. |
| **Fan** | Buyer, Follower (contextual) | The user consuming the Drop. |

## 3. Urgency & Scarcity (Premium Tone)
| Approved | Forbidden Substitutes | Context |
| :--- | :--- | :--- |
| **Available Now** | HURRY!, Act Fast! | Indicating immediate availability. |
| **Limited Release** | Almost Gone!, Rare | Indicating scarcity without panic. |
| **Exclusive Access** | VIP Only, Secret | Indicating high-tier availability. |

## 4. Errors & Operations (Truth)
| Approved | Forbidden Substitutes | Context |
| :--- | :--- | :--- |
| *(Declarative state)* | **Oops**, Uh oh, Yikes | Error headings. State what failed directly (e.g., "Connection Failed"). |
| **[stale]** | (Silent), Cached | Data that is older than realtime thresholds. |
| **[fallback]** | Simulated, Mock | Synthetic or secondary data when primary source fails. |
| *(Direct Truth)* | "It looks like..." | Never guess the state. Tell the user what the system knows. |
