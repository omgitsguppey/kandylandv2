# Module Coverage Source Policy

Batch 34 defines module coverage from explicit module source policy instead of a universal GA4/Event facts/Telemetry logs checklist.

GA4 is not a universal required source. It is optional or external evidence for internal product truth modules such as Admin, Runtime, Support, and AI Debug. Required beta modules declare canonical sources, accepted substitutes, dependent panels, validators, pass policy, block policy, and exact next action.

Optional module gaps are displayed separately and do not block required analytics module parity.
