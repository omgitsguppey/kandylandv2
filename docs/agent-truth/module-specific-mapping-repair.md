# Module Specific Mapping Repair

Daily Tasks now counts task lifecycle evidence. Task Guidance counts task pipeline evidence. Engagement counts module-specific event facts plus session, watch, page, or guest evidence. Admin and Runtime use internal admin truth, debug evidence, and route runtime sources instead of GA4.

Navigation remains blocked when page view, route runtime, and page rollup evidence are all absent. Auth and Notifications remain blocked until their canonical outcomes or accepted substitutes land for the selected range.
