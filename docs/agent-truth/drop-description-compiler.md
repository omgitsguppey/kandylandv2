# Drop Description Compiler

Drop description generation is deterministic-first and seedless.

- Canonical compiler: `src/lib/drop-descriptions/drop-description-compiler.ts`
- Source marker: `data-description-source="deterministic-patterns"`
- AI polish marker: `data-description-ai-polish="optional"`
- Default output: 3 options (`default`, `urgency`, `sensory`)

Doctrine:
Descriptions must always return useful options from title/flavor/creator context without starter text. AI polish is optional and replaceable.
