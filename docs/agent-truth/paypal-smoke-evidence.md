# PayPal Smoke Evidence

Formal acceptance owner: [Provider-Backed Source Activity Evidence](../../agent/evidence/provider-smoke/README.md). That owner and `scripts/agent/validate-provider-smoke-evidence.ts` define the current artifact, redaction, revision, freshness and required-check contract.

Status owner: `agent/state/provider-smoke-evidence.generated.json`, regenerated by `npm run check:provider-smoke-evidence`. Read the current artifact instead of copying its status into this document.

Screenshots and operator reports may provide optional context. They do not clear the provider gate. Local fixtures, source tests, a deployment receipt and maintenance responses also do not establish payment or GumDrop source-of-funds behavior.

Use `EVIDENCE_STRICT=1 npm run check:provider-smoke-evidence` for formal signoff after attaching actual redacted evidence through the canonical owner. An incomplete or missing artifact remains unresolved.

Payment/webhook work has no approved maintenance exception. Use the [maintenance contract](maintenance-mode-cost-contract.md) and an explicitly approved target before any provider action; a verification command is not permission to perform a financial transaction.
