## 2026-04-01 - Optimize loop processing and object cloning in Dashboard CollectionList\n**Learning:** High performance impact observed when large datasets are mapped multiple times (e.g. `map` -> `filter` -> `filter`) in hot-path React `useMemo` blocks. Specifically, `applyDropStatus` cloning objects inside `map` before a subsequent `filter` abandons them creates a significant garbage collection load.\n**Action:** Use a single-pass `for...of` loop to iterate elements, defer object cloning until element is validated to match criteria, and combine multiple aggregations inside the same iteration pass.
