## 2026-05-31 - Admin Payload N*M Array Iteration Loop Bottleneck
**Learning:** Found an `O(N)` `.find()` search inside an `O(S * A)` nested `.map` loop generating debug admin UI payload `RolloutActorEvaluationRow`s in `src/app/api/admin/debug/route.ts`. Given the large numbers of items and iterations expected on a large debug dump, this creates heavy main-thread blocking behavior and slow responses in V8 execution.
**Action:** Lift static lookup data into an `O(1)` Map, `rolloutItemsMap`, constructed natively via `new Map(rolloutItems.map((item) => [item.id, item]))`. Map gets in loops effectively remove one of the multiplication factors, dramatically speeding up data resolution in deep mapping operations (reduced 6.6ms -> 0.08ms in test mock). Make sure to properly coalesce missing items for strict TS types with `?? ""` since `get()` may return undefined.
