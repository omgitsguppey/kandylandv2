# Jessi Ray Signup + Feedback Playbook

This package is the v1 operator kit for routing Jessi Ray's DM and reply traffic into one clear KandyDrops action.

Primary page:
- `https://www.kandydrops.com/creators/jessiray`

Core product truths this kit assumes:
- Free signup creates a real KandyDrops account
- New fans currently start with `50` welcome GumDrops
- Following and creator alerts are free
- A text creator message currently costs `1` GD
- Daily check-in currently pays `10` to `70` GD
- More expensive asks can step up into custom requests, bookings, or subscriptions
- Referral is internal tracking only for this playbook, not the main user-facing incentive

Files in this package:
- `jessi-ray-dm-script-sheet.md`
- `jessi-ray-walkthrough-card.md`
- `jessi-ray-feedback-prompt-card.md`
- `jessi-ray-confusion-tags.md`
- `jessi-ray-weekly-scorecard-template.csv`

How to use this package:
1. Put the public creator page link in Jessi's bio, DM shortcuts, and story links.
2. Use the DM script sheet to route every fan into one concrete ask.
3. Use the walkthrough card when someone says yes but does not know what to do next.
4. Ask the feedback prompt only after the fan completes one meaningful action.
5. Log outcomes and confusion reasons in the weekly scorecard.

Operating rule:
- One fan ask
- One KandyDrops CTA
- One next step

Do not pitch "the platform" first.
Pitch the exact thing the fan asked for, then route them into KandyDrops to get it there.
