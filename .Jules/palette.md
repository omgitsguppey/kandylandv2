## 2025-02-12 - Missing aria-expanded on collapsible section toggle
**Learning:** Found an accordion toggle button in `CreatorDashboardSettingsHub` (`<button onClick={onToggle}>`) that visually expanded sections but did not programmatically announce its state to screen readers. React navigation and toggle components missing `aria-expanded` are an accessibility anti-pattern.
**Action:** When implementing or modifying expand/collapse functionality (like a toggle button), always map the boolean visibility state (e.g., `expanded`, `isOpen`) directly to the `aria-expanded` attribute on the triggering `<button>`.
